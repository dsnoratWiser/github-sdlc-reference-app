# Architecture Overview

## Purpose

This repository is a reference application used to learn and demonstrate a complete GitHub-based software development lifecycle.

## Repository Areas

### src

Contains the application source code.

### tests

Contains automated tests for the application.

### docs

Contains architecture, development, and engineering documentation.

### .github

Contains GitHub-specific configuration such as workflows, issue templates, pull request templates, and repository automation.

## Architecture Decisions

Significant architecture decisions will be documented separately using Architecture Decision Records (ADRs) under the docs/adr directory.
